# הסטודיו של תמימה — דמו אינטראקטיבי

דמו פרונט-אנד בלבד (HTML/CSS/JS, ללא build step) לפרויקט גמר אקדמי: מערכת CRM וניהול לסטודיו קרמיקה.

**[צפייה בדמו החי](https://dvashnesimi2011-dev.github.io/)**

שלוש חוויות מוצר:
- **לקוח/ה** — הזמנת סדנה, כולל נעילת משבצת לתשלום ו-fallback בהתנגשות
- **תמימה (ניהול)** — דשבורד, ניהול סדנאות ושיעורים, הפקת קבלות
- **סטודנט/ית** — מעקב שיעורים, ביטול לפי מדיניות, קביעת השלמה

כל הנתונים מדומים. אין שרת, אין API, אין שמירה אמיתית.
